AI Screen Agent: ห้องทดลองสมอง

เครื่องมือนี้ใช้พิสูจน์ตรรกะของ AI Agent ของคุณ โดยการแปลงภาพหน้าจอและคำสั่ง ให้กลายเป็นแผนการกระทำ (JSON Action Plan)

🧪 ห้องทดลอง
รองรับการวางภาพหน้าจอเป็นลิงก์หรือคำบรรยาย แตกคำสั่งออกเป็นขั้นตอนอัตโนมัติ ส่งออก JSON Action Plan พร้อมอธิบาย 
{
  "actions": [],
  "explanation": "กรอกข้อมูลด้านซ้ายเพื่อเริ่มสร้างแผนการกระทำ"
}
